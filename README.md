# CurrencyFlow 💱

A modern and responsive currency converter application built with **React, Vite, and Tailwind CSS**.

CurrencyFlow is a hands-on React project focused on learning custom hooks, reusable components, API integration, and state management.

> 🚧 **Project Status:** In Development

## ✨ Features

- Currency exchange rate data fetching using a custom React Hook.
- Reusable currency input component.
- Dynamic currency selection.
- React state management.
- Responsive user interface.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **API Integration:** Currency Exchange Rate API

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Israt-Art/currency-flow.git
```

### 2. Navigate to the project folder

```bash
cd currency-flow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local development URL in your browser.
